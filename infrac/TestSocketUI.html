WebSocket Demo

Cách test

  1. Test qua API của project

    Gọi các API có tích hợp chức năng thông báo như ASSIGN task, UPDATE task,...

  2. Test trực tiếp trên giao diện này

    Thêm ô nhập email người nhận và nội dung → bấm nút “Gửi tin nhắn” để gọi API từ frontend (dễ kiểm tra real-time qua WebSocket).

    Gửi thông báo (Cách 2)

  3. Test bằng Postman

    Dùng Postman gửi request đến:

    • Auth:
      POST http://localhost:8080/api/auth/v1/login
      JSON: {"email": "email của bạn", "password": "password"}
    • Gửi cho user cụ thể:
      POST http://localhost:9998/api/notification/v1/notifications/toUser/{email}
      Thay {email} bằng email muốn gửi và kèm access token.
    • Gửi cho toàn bộ user đang đăng nhập:
      POST http://localhost:9998/api/notification/v1/notifications/toAll
